# Testing
Read when: writing or running any step's Test, or closing a phase.

## Commands
- Defined as the code appears (Phases 0 to 3); write them here then.

## What "verified" means
- Wake phrase: 20 spoken tries and 20 minutes of normal noise, counts printed (phase 1.1).
- Command picker: 40-sentence test file, at least 90% right (phase 2.3).
- Answers: spoken text compared with the project files.
- Dashboard: playwright-cli screenshots; data equals the local feed.
- Anything that changes something: a before/after file comparison and the log line; mishear test of 50 commands (phase 5.5).
- Security: /security-review plus probing the running local address from another device and with bad input (phase 5.6).
- Measurements are measured, never guessed (PC_FIT.md).
