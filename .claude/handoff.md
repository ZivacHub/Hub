## Gotchas a fresh session would get wrong (max 8, only things still true)
- NEVER send a message from outside (`claude -p --resume`, `claude stop`, `--bg --resume`) into a chat the open list (`claude agents --json`) shows as open (Ivan's real chats): it splits it silently. Real tests only with chats the test created itself; stop them afterwards. Pressing the real "Open this chat" opens a real chat window for Ivan: leave it to him.
- A test that sends chat-start for a REAL project with a REAL task starts a real chat. Never write one into a self-test; use an unknown project or an empty task. The chat-open-app self-test uses a fake opener (openHooks): keep it that way. Look at /api/game after touching game-mode wiring.
- The dashboard is started by `Start Hub Dashboard.bat nobrowser` (a minimized window "Hub dashboard"; closing it stops it). It stops by itself now and then (found stopped today): check http://127.0.0.1:4780 before relying on it. Server code changes need a restart; page files are read fresh. Never start a second real-mode server beside it; test with `--demo` on a spare port (`HUB_PORT`, `--demo-chats=empty`, `--demo-helpers=empty`, `--demo-game=...`).
- The repo is PUBLIC and Ivan wants every update pushed: list the files and scan for keys first; screenshots only from `--demo`. `.playwright-cli/`, `data/`, `logs/` and `.claude/helpers/` are git-ignored.
- Folder rule: this chat owns tools/dashboard/, config/ and the dashboard docs; the Jarvis chat owns tools/jarvis_trial/.
- D31/D37: game mode slows or pauses only what the Hub started (including working Hub chats) plus the openshorts-backend container and Ollama's model. Chats of the app and the browser are never touched.
- Strict Content-Security-Policy: no inline styles or scripts. POST routes need the per-run token, same Origin, JSON, confirm:true. Ports: never 8765 or 8000; Manager on 18000; dashboard on 4780.
- Test files: write with node, not PowerShell Set-Content (BOM; a PowerShell pipe into node adds a BOM too). Write scripts and big texts with the file tool. A test script that spawns a server or chat must wait for the child's exit. Do not work around a blocked taskkill /T. Windows start-up is changed only by Ivan running Install Hub Autostart.bat.
