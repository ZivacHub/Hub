## Gotchas a fresh session would get wrong (max 8, only things still true)
- NEVER send a message from outside (`claude -p --resume`, `claude stop`, `--bg --resume`) into a chat the open list (`claude agents --json`) shows as open (Ivan's real chats): it splits it silently. Real tests only with chats the test created itself. A test with chat-start for a REAL project and a REAL task starts a real chat; the chat-open-app and Start with Windows self-tests use fakes (keep it that way; no test may write the registry, the Startup folder or open a real chat).
- The dashboard on 4780 stops by itself now and then (found stopped three times): check http://127.0.0.1:4780 before relying on it. The Hub app starts its own if none runs. Never start a second real-mode server beside a running one; test with `--demo` on a spare port (`HUB_PORT`, 4792 for the app self-test; `--demo-chats=empty`, `--demo-helpers=empty`, `--demo-game=...`). Server code changes need a restart; page files are read fresh.
- The app self-test `node tools/app/selftest.mjs` flashes a sample-data window for about 40 s and must leave no Electron or node process behind (check `tasklist | grep -i electron`). tools/app/node_modules (383 MB) is git-ignored; a fresh checkout needs `npm install` in tools/app (it also downloads Electron's program).
- The repo is PUBLIC and Ivan wants every update pushed: list the files and scan for keys first; screenshots only from `--demo`. `.playwright-cli/`, `data/`, `logs/`, `.claude/helpers/` and node_modules are git-ignored.
- Folder rule: this chat owns tools/dashboard/, tools/app/, config/ and the dashboard docs; the Jarvis chat owns tools/jarvis_trial/.
- D31/D37: game mode slows or pauses only what the Hub started (including working Hub chats) plus the openshorts-backend container and Ollama's model. Chats of the app and the browser are never touched. Game mode does not touch the keyboard or any Windows setting.
- Strict Content-Security-Policy: no inline styles or scripts. POST routes need the per-run token, same Origin, JSON, confirm:true. Ports: never 8765 or 8000; Manager on 18000; dashboard on 4780; app self-test 4792.
- Write files with the file tool or node, not PowerShell Set-Content (BOM) and not echo/heredoc for .bat files (a shell once ate every backslash of Start Hub App.bat). Windows start-up is changed only by Ivan: the "Start with Windows" click in the icon menu (or the old Install Hub Autostart.bat). Do not work around a blocked taskkill /T.
