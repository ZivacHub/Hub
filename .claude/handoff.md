## Gotchas a fresh session would get wrong (max 8, only things still true)
- Start everything with tools/jarvis_trial/start_jarvis_trial.ps1 (speaker, relay with --speak, Jarvis, closes the "Model recommendations" notice, hides the face). Never start Jarvis.exe alone (localFiles can delete files). Jarvis's own voice is ON but muted per app by the speaker service so its 8 s follow-up window opens when Daniel finishes. Jarvis sometimes is simply not running (state file %TEMP%\jarvis_state says "asleep"): check before a demo. To load a changed relay or Jarvis config, stop the relay python processes (and Jarvis.exe for config) first, then run the script.
- C:\Users\Ivan\.config\jarvis\config.json holds the Gemini key: never print, copy or commit it; JarvisTrial\config_*.json backups hold it too (config_pre_patience.json is the newest). Scripts may read it in-process (tests do), never echo it.
- Relay (port 8787) knobs: RELAY_FIRST_BYTE_S (5), RELAY_BACKUP_MODELS (gemini-3.1-flash-lite), RELAY_BANTER (30). It never logs what was said; `kind` is only the first 60 chars of Jarvis's own fixed prompt. Tests that call it add lines to relay_log.jsonl (git-ignored).
- tests/tool_pick_test.py through the live relay would make Daniel read all 44 answers: run a second relay without --speak (python tools/jarvis_trial/gemini_relay.py 8790) and set PICK_URL / PICK_MODEL; it overwrites tests/tool_pick_results.json (the step 2.3 proof): `git checkout` it afterwards. tests/persona_samples.py and gemini_latency.py talk to Google directly (nothing is spoken).
- Gemini 3 needs "thought signatures" on function-call history, so tests cannot fake tool-call messages; paste tool results into a user message instead.
- Mic-path tests use computer voice plus temporary settings voice_device "Microphone Array (Realtek(R) Au" and hot_window_enabled false (remove afterwards); Stereo Mix does not work. Never take full-screen screenshots.
- The `claude` command-line login is separate from the desktop app and expired once. Never ask the Claude helper to read real key files. Write files with the Write tool; PowerShell Get-Content/Set-Content breaks non-ASCII characters.
- Use `.venv\Scripts\python.exe` in Hub (Python 3.11.9); Node 24 for tools/hub_status. Disk about 39 GB free; any download needs his yes and the size told first. Never post, spend, delete/overwrite files or speak secrets on its own.
